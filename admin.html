GitHub sign in protects publishing

This website is hosted as static pages. The trusted login and permission check happen in GitHub: only accounts with write access can save a live change. Visitors can read public job listings, but cannot publish changes to Meridian’s website.

PUBLISH A JOB UPDATE
  1. Sign in to the authorized GitHub account and choose Run workflow.
  2. Select Add, Edit, Close or Reopen, then fill in the role details.
  3. Run the workflow. It prepares a pull request with the proposed jobs.json update.
  4. Review and merge the pull request to publish. GitHub Pages then deploys the update.
